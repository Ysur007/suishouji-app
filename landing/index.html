像发消息一样记笔记 数据留在你自己的机器上

React 前端配一个 Node 同步服务，所有记录落在同一个 JSON 文件里——不依赖云服务、数据库或对象存储。克隆下来，一条命令就能用。

Windows · Android · 浏览器。安装包在 Releases，也可以自己跑一份。

单端口 8787 · 数据只落在 data/ 一个目录 · 没有对象存储

未做修饰的界面截图

记录的成本，压到一次回车

速记的敌人不是忘记，是"打开一个表单"。所以这里没有表单：一个输入框，按 Enter，写下的东西立刻成为一条记录。

  1. 写

    一句一句，不必组织

    想到什么写什么。Enter 发送，Shift + Enter 换行；图片可以选、拖、粘贴，客户端先压到 1600px，单条最多 4 张。写完还能置顶、归档进文件夹、或多选后批量删。

    Enter 发送4 张图置顶与归档

  2. 到

    两台设备之间，约 100ms

    每条写入是一条带 HLC 时间戳的不可变操作，先落本机再发服务端；服务端按 op id 幂等收下，再广播给同一空间的其他连接。断网照常记，恢复后自动补发。

    离线可用断线补发增量同步

  3. 找

    三个月后，还找得回来

    整理按主题聚类、抽出一份可勾选的待办、挑出值得回看的句子；对话基于你自己的记录问答，回答下面挂着原文引用。时间线、空间、文件夹是三种不同的回顾方式。

    主题聚类待办可勾选答案带引用

  4. 走

    备份就是拷一个文件

    全部数据在 data/db.json。导出可以选范围（全部 / 近 30 天 / 某个群）和来源（本机 · 服务端）。没有导出配额，也没有"升级会员才能带走"。

四个页面，一套语言

记录 / 整理 / 对话 / 我的 是一级页面，共用同一个页头。桌面三栏，平板收掉一层，手机换成底部标签栏——不是把栏压窄，是换一个导航载体。

记录 · 当一个聊天窗口用。往上翻超过一屏，右下角浮出「最新」，点一下平滑回到底部。

整理 · 批处理：选范围 → 生成 → 看结果，报告留在左侧历史里，可以回头比。

对话 · 检索式问答，回答下面挂着可点回原文的引用。可流式输出，也可以中途停。

时间线 · 按时间铺开，标出隔了多久、是当天第几条、来自哪台设备。

空间 · 卡片流加全文搜索，适合"我记得写过，但不记得哪天"。

文件夹 · 五层 CSS 叠出厚度的拟物图标，六种色调其实是六个明度档。

移动端 · 单列记录流，底部四个标签，长按气泡出菜单。

三个打开它的时刻

它不试图成为知识库，也不做团队 Wiki。它只负责把"想到的那一秒"留下来，并在你需要的时候还给你。

它也明确不适合一些事

这些不是待办清单，是设计取舍。写在这里，省得你部署完才发现。

  • 单文件 JSON + 全量内存 适合个人和小团队。几十人同时写，该换 SQLite 或 Postgres——Op 模型不用改，只换持久化层。
  • 没有端到端加密，服务端能读到明文，data/db.json 里就是原文。别把不能外泄的东西放进来。
  • 冲突粒度是整条记录的后写覆盖。两个人同一秒改同一条，会丢掉其中一次。要逐字合并得换 CRDT。

三条路，选最短的那条

最快的一条是 Docker：一个服务、一个端口、一个数据目录。想改代码就走本地开发，只想用就走客户端。

Docker 最省事 
git clone https://github.com/Ysur007/suishouji-app.git
cd suishouji-app
docker compose up -d

数据挂在 ./data，升级只要 git pull && docker compose up -d --build。

本地开发 改代码 
npm install
npm run dev

前端 5173，同步服务 8787，Vite 已把 /api、/ws 代理过去。

客户端 不折腾

Windows 安装包把前端和服务端一起打进 exe，数据在 %APPDATA%\Suishouji；Android 包把页面打包进 app，服务器地址可以随时改。

两个包都没做代码签名：Windows 首次运行会被 SmartScreen 拦（更多信息 → 仍要运行），Android 是 debug 签名，适合自用。

现在把它放到你自己的机器上。

不需要信用卡，不需要注册账号，也不需要先看一段演示视频。一条命令之后，记录就归你了。
